Marin Learn stores instructional narrative in reusable ContentUnits. A learning material, quiz, or slide deck references those units rather than maintaining an independent copy.

| Output | How it uses canonical content |
| --- | --- |
| Reading view | Renders the full ordered material |
| Quiz | Links questions to the source content and objective |
| Slides | Uses a ContentUnit title, abstract, or full body |

This does not prohibit presentation-specific information. Speaker notes, slide layouts, and question feedback have distinct purposes and remain separate.
